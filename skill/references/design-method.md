# 图标系统设计方法

先理解产品中“要表达什么”，再选择几何；不能先堆 SVG 再补语义。阅读用户授权的产品资料、界面和既有规范，区分确定事实与设计推断。资料不全时用对话补足，不在 HTML 增加需求表单。

## 系统一致性

- 项目记录设计目的、风格偏好、受众、场景、范围和约束。设计目的回答为什么做，风格偏好记录用户的审美倾向；不要用同一“目标”字段混装二者。方案承载具体设计思路和造型探索，不能将 Agent 的造型建议预先写成项目需求。用户明确指定的造型要求作为约束保留来源，不擅自删掉。每个方案由 Agent 制定自己的网格、安全边距、描边、端点、连接、圆角和光学修正规则。
- 语义清单稳定表达每个动作/对象，名称可显示，concept 解释含义。tags 只填真实可检索类别、对象、动作或同义词；不得填装饰性“现代”“好看”、方案名、内部任务状态。没有实际标签就不造空筛选。
- 同一语义的 light/regular/bold、filled/outline、16/24/64 px 可为变体；不同应用角色如应用身份和状态栏入口是不同图标。不同尺寸要独立检查，不能把缩放复制当作光学设计完成。
- 从几枚有代表性的复杂度、斜线、曲线、开闭轮廓图标验证系统，再按已登记目标批次扩展。建议小批次约 20 个目标，不一次倾倒全库。

## 显式几何

矩阵是源，SVG 是编译产物。使用 rect/ellipse/line/path/group/boolean/instance，不输入原始 SVG、脚本、URL 或任意路径字符串。路径每个节点记录 point、in、out 的绝对局部坐标；null 是没有柄。仿射变换 `[a,b,c,d,tx,ty]` 表示 `x'=a*x+c*y+tx, y'=b*x+d*y+ty`，是图层几何变换，不是画布缩放。transform_layer 替换该图层变换，不累乘。

构造要简洁、可维护；重复结构用明确组件，避免循环。布尔支持并、减、交、异或，输入必须是闭合填充轮廓。拆分实例保留实际变换并去除组件依赖；节点移动不能默默创建另一尺寸版本。

同时检查数学与视觉：真实曲线极值、描边墨迹和安全边界；小尺寸像素节奏、视觉中心、圆形/方形视觉重量；浅深底和实际尺寸。几何通过不等于用户认可。把设计推理留在对话，不作为默认界面评价。

## 固定查看内容

图标列表平铺，不混排方案，不保留“选中过”的卡片态。点击进入图标详情；返回列表恢复查询与位置。

结构视图选择明确尺寸/样式/轻重，查看图层、节点和正反色实际尺寸；工具可读到当前选区。场景视图属于整个语义图标，列出所有相关用途，不继承隐藏结构选区，不加场景下拉、重复方案名称、模拟预览免责声明或主观优缺点评价。

固定用途模板是应用图标、工具栏、状态栏、导航。仅展开已绑定用途，显示源变体与展示尺寸；尺寸对比与反色是查看状态，不生成新变体。没有绑定就显示空状态，不猜应用场景。用户在场景点样本时可回到相应源变体结构。

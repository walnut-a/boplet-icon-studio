### 项目库/父目录识别（最后完成，未部署）

用户期望选择存放多个项目库的总目录，就能看到里面的项目，不必知道 `library.json` 在哪一级。

- 直接选择项目库：按原业务核心打开。
- 选择父目录：**只检查下一层目录**，汇总其中有效项目库的项目；不无限递归扫描磁盘。
- 卡片标记所属项目库；打开时绑定对应子目录，不移动、复制或合并项目。
- URL 查询参数 `library` 保留相对库路径，配合原 hash 视图恢复；测试覆盖不同库出现相同项目 ID，刷新与浏览器返回不串库。
- 父目录列表包含空项目库入口；可以打开并通过原流程开始创建。
- 选择真正空目录：显示“准备好创建第一个项目”，保留授权。**选择时不创建 library.json**；Agent 完整加载 Skill 后，通过既有创建操作初始化。
- 单个项目数据目录、旧格式、损坏/不支持的数据分别反馈；子目录旧格式不会遮蔽可用项目。
- 显式刷新重新扫描目录；没有常驻递归文件监视器。
- **跨库汇总仅是网页查看层**，没有改动文件格式、单库操作合同或本地 CLI 的根目录约定。
